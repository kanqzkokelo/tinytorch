## Exact forward math (from llama.cpp build_gemma4)

```
inpL = embed(tok) * sqrt(1536)

# ONCE before layers (per position):
pe_raw[tok] = dequant(per_layer_tok_embd row tok)          # 8960 floats, *16 = sqrt(256)
proj = rmsnorm( (per_layer_model_proj @ x_scaled) * (1/sqrt(1536)),   # reshape [256][35]
                per_layer_proj_norm )
PLE = (proj + pe_raw) * (1/sqrt(2))                         # cache per position: [35][256]

for l in 0..34:
    cur = rmsnorm(inpL, attn_norm[l])
    q = Wq@cur -> [8*256]; q = per-head-rmsnorm(q, q_norm[l])     # hd=256
    k = Wk@cur -> [1*256]; k = per-head-rmsnorm(k, k_norm[l])
    v = Wv@cur -> [1*256]; v = rmsnorm(v) WITHOUT gamma           # plain!
    q,k = rope_neox(q,k, pos, base_l)        # base: check layer type (see below)
    att = flash(q, K_cache[l], V_cache[l], scale=1.0)              # NO 1/sqrt(hd)!
    cur = rmsnorm(Wo@att, post_attention_norm[l])
    inpL = cur + inpL                                              # residual

    cur = rmsnorm(inpL, ffn_norm[l])
    h = gelu(gate@cur) * (up@cur)                                  # GeGLU
    cur = rmsnorm(down@h, post_ffw_norm[l])
    inpL = cur + inpL                                              # residual

    # MatFormer per-layer embedding block:
    g  = gelu(inp_gate[l] @ inpL)                  # [256]
    g *= PLE[l]                                    # elementwise
    p  = rmsnorm(pl_proj[l] @ g, ???)              # see OPEN QUESTION
    inpL += p
    inpL *= layer_output_scale[l]                  # scalar
```

Final: logits = softcap(tanh-form, c=30)( token_embd @ rmsnorm(inpL, output_norm) )

## OPEN QUESTIONS (resolve empirically during bring-up)

3. `layer_output_scale` may need sigmoid/tanh first — start raw, flip if off.
4. V-norm epsilon: same 1e-6 assumed.

### KV sharing (confirmed from HF source)
`num_kv_shared_layers = 20`: layers 20..34 reuse the K/V states of the last
full/sliding layer before them (`shared_kv_states[layer_type]`, keyed by TYPE:
all sliding layers share one cache, all full layers share another).
Implication for our engine: only 15 real KV caches needed (one per non-shared
layer), but shared layers must still apply their own o-proj.

### Attention scaling (confirmed)
`self.scaling = 1.0` — NO 1/sqrt(head_dim). Already implemented via trait.

### V-norm (confirmed)
`v_norm = RMSNorm(head_dim, with_scale=False)` — plain, no gamma, applied to v
BEFORE rope/caching. Already implemented via ones-gamma trick.

### QK-norms (confirmed)
q_norm AND k_norm are RMSNorm WITH learnable scale, eps=rms_norm_eps(1e-6),
applied per-head pre-rope. Already implemented.

### MLP (confirmed)
gate/up/down + act_fn = gelu_pytorch_tanh. `use_double_wide_mlp` doubles
intermediate size on KV-SHARED layers (explains 12288 vs 6144 ffn tensors).

### RoPE (confirmed)
Half-split (NEOX-style rotate_half in HF). Full head_dim rotation (no partial).
Per-layer-type bases: sliding uses rope_freq_base_swa, full uses
rope_freq_base. Learned `rope_freqs.weight` [head_dim] exists as freq_factors —
VERIFY its exact role in llama.cpp ggml_rope_ext call (freq_factors scales
inv_freq per pair) before implementing; may be identity-equivalent to base swap.

### PLE pipeline (confirmed by GH issue #45206 + HF docs)
Exactly as implemented in our compute_ple():
1. token_identity = per_layer_embed_lookup(ids) * sqrt(256)
2. proj_ctx = rmsnorm( Linear_1536_to_8960(x_scaled) * (1/sqrt(1536)) )
3. PLE = (proj_ctx + token_identity) * (1/sqrt(2)), reshaped [35][256]
4. Layer l consumes slice l AFTER mlp residual:
   g = gelu(per_layer_input_gate @ x); g *= PLE[l];
   x += rmsnorm(per_layer_projection @ g);
   x *= layer_scalar
Common pitfall documented: missing sqrt(256) scale gives 16x-too-small outputs
(we already handle).
